# Zigg Investment Dashboard

En visuell MVP för investeringsidéer med:

- dagliga top 10-idéer
- korta trades vs långsiktiga case
- fundamental + teknisk analys
- grafisk presentation
- utveckling sedan köpsignal

## Viktigt

Detta är beslutsstöd och prototypdata, inte finansiell rådgivning.

## MVP just nu

- snygg dashboard
- top 10-tabell
- teknisk exempelfraf
- score breakdown
- metodiksektion

## Nästa steg

- riktig marknadsdata
- automatisk uppdatering
- historikdatabas för rekommendationer
- riktiga candlestick-grafer
- RSI, MACD, MA50/MA200
- filtrering och watchlists
- portfolio tracking
